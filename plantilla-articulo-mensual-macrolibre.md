## ESTRUCTURA DEL ARTÍCULO

---

### TÍTULO (para Google — copialo exacto en el `<title>` y en el `<h1>`)

```
Inflación, dólar y resultado fiscal en [MES] [AÑO]: qué dicen los datos de la economía argentina
```

**Alternativas si hay un dato dominante ese mes:**
```
Inflación de [MES] [AÑO] en Argentina: [X]% — qué pasó y qué esperar
Déficit fiscal de [MES] [AÑO]: Argentina [cerró/no cerró] en equilibrio
Reservas BCRA en [MES] [AÑO]: qué está pasando con las divisas
```

> 💡 SEO TIP: El título tiene que tener el mes y el año escrito completo. La gente busca "inflación mayo 2026", no "inflación este mes".

---

### META DESCRIPTION (máximo 155 caracteres — va en el `<meta description>`)

```
Los datos macroeconómicos de [MES] [AÑO] en un solo lugar: inflación, tipo de cambio, reservas y resultado fiscal. Fuentes oficiales, actualización en tiempo real.
```

---

### INTRODUCCIÓN (50-80 palabras)

```

```

## LOS 5 INDICADORES PRIORITARIOS

---

### 1. 📈 INFLACIÓN

**Dato del mes:**
```
El IPC de [MES] [AÑO] fue de [X]% mensual, acumulando [X]% en lo que va del año 
y [X]% interanual. [Subió / Bajó / Se mantuvo estable] respecto al mes anterior ([X]%).
```

**Contexto (2-3 oraciones):**
```
[Qué rubros empujaron más: alimentos, servicios, tarifas, etc.]
[Si aceleró o desaceleró respecto a la tendencia reciente]
[Una comparación histórica relevante si aplica — ej: "el nivel más bajo desde X"]
```

**Link interno obligatorio:**
```
→ Ver el indicador en tiempo real: [Inflación — MacroLibre](/indicadores/inflacion-argentina)
```

---

### 2. 💵 TIPO DE CAMBIO

**Dato del mes:**
```
El tipo de cambio oficial cerró [MES] en $[X]. El dólar blue promedió $[X] durante el mes, 
con una brecha cambiaria del [X]% respecto al oficial.
El tipo de cambio real multilateral [se apreció / depreció] un [X]% en el período.
```

**Contexto (2-3 oraciones):**
```
[Movimientos relevantes durante el mes — intervenciones, saltos, calma]
[Relación con las reservas o el contexto político si es relevante]
[Qué implica para exportadores/importadores si hubo movimiento significativo]
```

**Link interno obligatorio:**
```
→ Ver tipo de cambio en tiempo real: [Dólar y Tipo de Cambio — MacroLibre](/indicadores/tipo-de-cambio)
```

> 💡 SEO TIP: Usá las palabras "dólar blue", "tipo de cambio oficial", "brecha cambiaria" y "tipo de cambio real" — todas son búsquedas separadas con volumen propio.

---

### 3. 🏦 RESERVAS BCRA

**Dato del mes:**
```
Las reservas internacionales del BCRA cerraron [MES] en USD [X] millones 
([brutas / netas según disponibilidad]). [Subieron / Bajaron / Se mantuvieron] 
respecto al cierre de [MES ANTERIOR] (USD [X] millones).
```

**Contexto (2-3 oraciones):**
```
[Qué explica el movimiento: compras en el MULC, vencimientos, desembolsos FMI, etc.]
[Si hay algún nivel umbral relevante que se cruzó]
[Perspectiva para el mes siguiente si hay datos disponibles]
```

**Link interno obligatorio:**
```
→ Ver reservas en tiempo real: [Reservas BCRA — MacroLibre](/indicadores/reservas-bcra)
```

---

### 4. 📊 RESULTADO FISCAL (Déficit / Superávit)

**Dato del mes:**
```
El resultado fiscal [primario / financiero] de [MES] fue de [superávit/déficit] 
de $[X] millones/miles de millones. En lo que va de [AÑO], el resultado acumulado 
es de [superávit/déficit] de $[X].
```

**Contexto (2-3 oraciones):**
```
[Si se sostiene el equilibrio o hubo desvíos respecto a la meta]
[Qué rubros del gasto o la recaudación explicaron el resultado]
[Comparación interanual — ej: "mismo mes del año anterior fue déficit de X"]
```

**Link interno obligatorio:**
```
→ Ver resultado fiscal en tiempo real: [Sector Fiscal — MacroLibre](/indicadores/resultado-fiscal)
```

> 💡 SEO TIP: Usá las variantes: "déficit fiscal", "superávit fiscal", "resultado primario", "equilibrio presupuestario" — son búsquedas distintas. Incluí todas naturalmente en el texto.

---

### 5. 📉 POBREZA E INDIGENCIA (cuando haya dato nuevo — semestral)

> ⚠️ Este dato lo publica INDEC cada 6 meses. Cuando no hay dato nuevo, reemplazalo por:
> - Salario real (variación mensual)
> - Actividad económica (EMAE)
> - Balanza comercial

**Dato del período:**
```
Según el último dato del INDEC ([PERÍODO]), la tasa de pobreza fue del [X]% 
de la población ([X] millones de personas). La indigencia alcanzó el [X]%.
```

**Contexto (2-3 oraciones):**
```
[Comparación con el período anterior]
[Si mejoró o empeoró y qué factores lo explican — inflación, empleo, transferencias]
[Caveat: recordar que es dato semestral, no mensual]
```

**Link interno obligatorio:**
```
→ Ver indicadores sociales: [Pobreza e Indigencia — MacroLibre](/indicadores/pobreza-indigencia)
```
